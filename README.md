# ✈️ Flight Booking System

A full-stack Flight Booking System built using the MERN Stack. The application enables users to search for flights, book tickets, manage bookings, and securely authenticate using JWT.

## Features

- User Registration & Login
- JWT Authentication
- Flight Search
- Flight Booking
- Booking History
- Cancel Booking
- Admin Dashboard
- Responsive Design

## Installation

Clone the repository

Install dependencies

Backend

npm install

Frontend

cd client
npm install

Run Backend

npm start

Run Frontend

npm start
